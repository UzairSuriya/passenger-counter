# Passenger Counter App 🚂

A lightweight web application designed to track and log passenger counts in real time.

## 🚀 Live Demo
[View Live Project](https://github.com/UzairSuriya/passenger-counter)

## ✨ Features
* **Increment Counter:** Real-time count tracking with button interaction.
* **Save Entries:** Logs previous batch counts for quick record-keeping.
* **Responsive UI:** Styled layout with custom background assets.

## 🛠️ Tech Stack
* **HTML5:** Semantic document structure.
* **CSS3:** Custom styling, Flexbox positioning.
* **JavaScript (ES6):** DOM manipulation and event management.

## 📦 How to Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/UzairSuriya/passenger-counter.git](https://github.com/UzairSuriya/passenger-counter.git)
   ```
2. Open `index.html` directly in your browser.
